**Fundamentals of Image Processing** is a core undergraduate course (48 contact hours) for Software Engineering students at South China University of Technology.

This course introduces the fundamental theories and techniques of digital image processing, including:

- Image formation, sampling, and quantization
- Image enhancement (histogram processing, spatial filtering, frequency domain filtering)
- Image restoration and reconstruction
- Morphological image processing
- Image segmentation (thresholding, edge detection, region growing)
- Feature extraction and representation
- Applications in computer vision and pattern recognition

The course combines theoretical foundations with hands-on programming exercises using MATLAB/Python. It has been offered since 2016.
