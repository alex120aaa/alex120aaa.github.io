**Digital Logic** is a core undergraduate course (48 contact hours) for Software Engineering students at South China University of Technology.

This course covers the fundamental principles of digital logic design, including:

- Number systems and binary arithmetic
- Boolean algebra and logic simplification (K-map, Quine-McCluskey)
- Combinational logic circuits (adders, subtractors, encoders, decoders, multiplexers)
- Sequential logic circuits (flip-flops, registers, counters, state machines)
- Memory systems and programmable logic devices
- Introduction to hardware description languages

The course is taught in Chinese with English terminology, emphasizing both theoretical foundations and practical circuit design skills. It has been offered since 2016.
