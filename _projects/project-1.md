This project focuses on developing a robust, scalable system for mapping weed presence across broadacre farms using drone and satellite-based remote sensing. Delivered in collaboration with industry partners, the project integrates high-resolution imagery and deep learning to identify weed-infested regions and support variable-rate herbicide application.
